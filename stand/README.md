# Стенд ClickHouse

Версия: **25.8.33.6**. Требуется Docker с Compose.

1. Поместить `listening_events.csv.gz` (10 000 000 событий) в `stand/data/`, не распаковывая.
2. Из корня репозитория выполнить `docker compose -f stand/compose.yaml up -d --wait`.
3. Открыть http://localhost:8123/play. Пользователь: `student`, пароль: `takt`.
4. Только при первоначальной подготовке выполнить команды из [00_prepare_source.sql](00_prepare_source.sql) по одной.

Данные уже загружены. При повторном запуске контейнера загрузка не требуется. Повторный отдельный `INSERT` удвоит данные; для повторной подготовки нужен весь блок сброса и загрузки.

Данные ClickHouse сохраняются в именованном Docker-томе. Команда остановки из корня репозитория: `docker compose -f stand/compose.yaml stop`. Не использовать `down -v`, если нужно сохранить данные.

Файл событий исключён из Git.
